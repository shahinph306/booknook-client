## Project Name: BookNook – A Small Online Library

##  Live Site

**👉 https://booknook-client-liart.vercel.app*


## ✨ Key Features

 📖 **Browse & Search Books** – Explore a curated collection with instant search, category filters, and detailed book information including author, genre, and availability status
🔐 **Secure User Authentication** – Powered by BetterAuth, sign up, log in, and manage your profile safely with JWT-based session protection
📅 **Borrow & Return System** – Borrow books in one click, view your active borrowals, track due dates, and mark returns directly from your dashboard
📋 **My Borrowals Dashboard** – Keep full history of your borrowed books, see status at a glance, and never miss a return deadline
🎨 **Clean & Responsive Design** – Built with Tailwind CSS and ShadCN components; works smoothly on mobile, tablet, and desktop screens with dark mode support


## 🛠️ Tech Stack

- **Frontend:** Next.js 15 (App Router) + TypeScript + Tailwind CSS + ShadCN
- **Backend:** Next.js API Routes
- **Database:** MongoDB
- **Authentication:** BetterAuth (JWT-based)
- **Deployment:** Vercel
